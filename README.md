# Cómo clonar un repositorio de GitHub usando GitHub Desktop

Clonar un repositorio significa descargar una copia completa de ese proyecto desde GitHub a tu ordenador para poder trabajar en él localmente. 

Usar **GitHub Desktop** hace que este proceso sea visual y muy sencillo, sin necesidad de usar la línea de comandos o la terminal.

---

## Prerrequisitos

Antes de empezar, asegúrate de tener lo siguiente:
1. Tener instalado [**GitHub Desktop**](https://github.com/apps/desktop?ref_product=desktop&ref_type=engagement&ref_style=button) en tu ordenador (Windows o macOS).
2. Haber iniciado sesión con tu cuenta de **GitHub** dentro de la aplicación.
3. El enlace o la URL del repositorio que deseas clonar.

## Pasos para clonar el repositorio

Sigue estos pasos para descargar el proyecto en tu equipo:

### 1. Obtener el enlace del repositorio en GitHub
1. Abre tu navegador web y entra en [GitHub](https://github.com).
2. Ve al repositorio que quieres clonar.
3. Haz clic en el botón verde **Code**.
4. En la pestaña **Local**, selecciona la opción **Open with GitHub Desktop** (también puedes copiar la URL HTTPS si lo prefieres).

---

### 2. Abrir GitHub Desktop y clonar
* Si hiciste clic en *Open with GitHub Desktop* en el paso anterior, la aplicación se abrirá automáticamente con una ventana emergente para clonar.
* Si abriste GitHub Desktop manualmente:
  1. Ve al menú superior y haz clic en **File** > **Clone repository...** (o pulsa `Ctrl + Shift + O` en Windows / `Cmd + Shift + O` en Mac).
  2. Selecciona la pestaña **URL**.
  3. Pega la URL del repositorio en el campo **Repository URL**.
  4. En **Local path**, elige la carpeta de tu ordenador donde se guardará el proyecto.

---

### 3. Finalizar la clonación
1. Haz clic en el botón azul **Clone**.
2. GitHub Desktop descargará todos los archivos del repositorio en la carpeta que seleccionaste. 

¡Y ya estaría! Una vez finalizada la descarga, el repositorio aparecerá en la interfaz de GitHub Desktop y podrás empezar a trabajar, crear ramas y hacer cambios de forma local.
